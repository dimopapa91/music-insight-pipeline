# Waveline for AI agents (x402)

Waveline sells its artist insights to AI agents over x402. An agent asks for an insight, gets an HTTP 402 with the price, pays in USDC on Base, and receives the insight. No account, no API key, no card.

## Endpoint

`GET https://wearewaveline.com/api/insight?artist=<name>`

| Request | Response | Charged |
|---|---|---|
| no payment | 402 with the payment terms; the JSON body and the `PAYMENT-REQUIRED` header carry the same object | no |
| missing, empty or longer than 200 characters `?artist` | 400 `missing_artist`, returned before any payment is requested | no |
| paid, known artist | 200 with exactly four fields: `artist`, `insight`, `generated_at` (ISO-8601, UTC, ends in `Z`), `source` | yes, 0.005 USDC |
| paid, unknown artist | 404 `artist_not_found`, "You were not charged." | no |
| paid, temporary database error | 503 | no |

Payment terms: scheme `exact`, network `eip155:8453` (Base), asset USDC `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`, amount `5000` (0.005 USDC). Payments are settled through the Coinbase CDP facilitator, and only when the response is a success, so a 400, 404 or 503 never costs anything.

Free preview, no payment: `GET https://wearewaveline.com/api/insight/preview` returns one full sample insight with the same four fields, plus `preview`, `paid_endpoint`, `price`, `currency` and `network`, which the paid response does not include.

The insight text is Waveline's own AI-written analysis.

## Verify it yourself

These transactions can be checked on any Base explorer or RPC without trusting Waveline or nsgoods.

- Base Sepolia, test payment through the x402.org facilitator: `0x7cd0cd48ace84d5f019fc25a020cf45a6e7320294bb58a8ef2046e3d8b671617`
- Base Sepolia, test payment through the CDP facilitator: `0xc5226be6c786f6ca779792b49f4f845f7d9831934f3c663d7ce61eb9ce66ac18`
- Base mainnet, first real payment (26 September 2026): `0xdf63c126565fbc83a5aa1f5deb575c8f1757cc3a35a0871aff20f54d0ef740e3`

The mainnet transaction contains one USDC Transfer of 5000 to the Waveline payTo, submitted by a facilitator relayer, with `cdp_facil1` in its calldata. In the same test, a paid request for an unknown artist returned 404 and no payment was settled.

## Independent check
