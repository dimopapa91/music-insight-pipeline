# Waveline brand assets

| File | Use on |
|------|--------|
| `waveline-logo-on-dark.svg` / `.png` | dark backgrounds (lavender mark, white wordmark) |
| `waveline-logo-on-light.svg` / `.png` | light backgrounds (violet mark, near-black wordmark) |
| `waveline-mark.svg` / `.png` | icon only, dark backgrounds |
| `waveline-mark-on-light.svg` / `.png` | icon only, light backgrounds |
| `waveline-app-icon.svg` / `.png` | app/avatar icon: the mark on a black rounded tile (same as the favicon) |

All files have transparent backgrounds. The wordmark is set in Archivo Narrow
Bold (SIL Open Font License) and converted to outlines, so the SVGs need no
font. The mark is a single wave line that writes a W, with a vertical
gradient: `#f3eeff` → `#9d8ae6` on dark, `#7b63e6` → `#4a33b8` on light.
Wordmark: white `#ffffff` on dark, near-black `#0d0d0f` on light.

Public URLs: `https://wearewaveline.com/static/brand/<file>`
