# Waveline brand assets

The wordmark is set in **Barlow Condensed Black Italic** (SIL Open Font
License), the same type as the WAVELINE title on dimospapageorgiou.com, with a
violet extrusion that gives it depth. Text is converted to outlines, so the
SVGs need no font. All files have transparent backgrounds except the app icon.

| File | Use on |
|------|--------|
| `waveline-logo-on-dark.svg` / `.png` | wordmark for dark backgrounds (white face, violet extrusion) |
| `waveline-logo-on-light.svg` / `.png` | wordmark for light backgrounds (near-black face, lavender extrusion) |
| `waveline-mark.svg` / `.png` | the W alone, dark backgrounds |
| `waveline-mark-on-light.svg` / `.png` | the W alone, light backgrounds |
| `waveline-app-icon.svg` / `.png` | the W on a black rounded tile (same as the favicon) |
| `waveline-wordmark-header-*.svg` | the site header (lighter extrusion for small sizes) |

Colours: face `#ffffff` / `#0d0d0f`; W gradient `#f1ebff` → `#b3a0ff`;
extrusion `#8f7ddc`, `#5b3fd0`, `#3b2b8c`.

Public URLs: `https://wearewaveline.com/static/brand/<file>`
